🚀 Interface web de uma lista de casamento digital, onde o casal gerencia seus presentes e convidados navegam pela lista pública para escolher e "presentear" um item.

🛠 Tecnologias usadas
As seguintes ferramentas foram usadas na construção do projeto:

* React
* Vite
* React Router

✨ Pré-requisitos
Para rodar o projeto na máquina você precisará do Node.js instalado, que para rodar o projeto é necessário usar npm install, além do back-end rodando junto. Além disso, é bom ter um editor instalado para trabalhar como VSCode.

🎉 Rodando o projeto
```bash
cp .env
npm install
npm run dev
```
O site abre em `http://localhost:5173`.
